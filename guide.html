Part 1 • Architecture & Deployment

Full Installation & Setup Walkthrough

Step-by-step instructions to get your high-performance containerized ERP running from bare metal.

1

Prerequisites & Repository Clone

Ensure you have Docker Engine 24+ and Docker Compose v2 installed. Minimum host specs: 2 vCPUs, 4GB RAM (8GB recommended for full 278+ module suites). 

git clone https://github.com/rsnarsna/odoo.git
cd odoo
2

Credential Isolation (.env)

Copy the example environment template to create your production secret file. Secrets in .env are completely git-ignored. 

# Windows:
Copy-Item .env.example .env

# Linux / Mac:
cp .env.example .env
3

Start Containers (One-Command)

Launches PostgreSQL 16 (odoo_db) and Odoo 19.0 Community (odoo_web) with all addons mounted. 

docker compose up -d
Verify health: docker ps (odoo_db must show healthy).
4

The "Zero-Lock" Rule (Pro Tip)

Important: Never run bulk CLI module installations (odoo -i ...) while the web container is serving traffic! Concurrency causes PostgreSQL serialization deadlocks. 

# 1. Stop web service temporarily
docker compose stop web

# 2. Run your module installation container
docker run --rm --network odoo_network -v ... odoo:latest odoo -i  -d odoo --stop-after-init ...

# 3. Restart web service cleanly
docker compose start web

⚡ Direct Landing & Database Pre-Binding

Our configuration (config/odoo.conf) includes db_name = odoo. This ensures that every visitor lands directly at the clean login portal without being redirected to the database selector or creation manager.

Web Portal URL: http://localhost:8069/web/login Default Superuser: admin / admin

How to Use All Open Source Apps

Comprehensive user guide and workflow manuals for the 278+ deployed applications.

💼

1. Core Business Suite: CRM, Sales & Invoicing

🎯 CRM & Leads crm

  • Lead Ingestion: Incoming website messages automatically convert into CRM leads.
  • Kanban Pipeline: Drag cards across custom stages (New → Qualified → Proposition → Won).
  • Next Actions: Schedule calls, meetings, and follow-ups with automatic calendar sync.
  • Lead Probability: AI-driven scoring estimates win probability automatically.

📜 Quotations & Sales sale_management

  • Quote Builder: Create professional PDF quotes with custom product bundles and pricelists.
  • Online Client Portal: Send quotes via email with instant client electronic acceptance.
  • Order Confirmation: Automatically reserves inventory and generates warehouse pickings.
  • Automated Invoicing: Invoice based on ordered quantities or delivered quantities.

🧾 Invoicing & Payments account

  • Draft Invoices: 1-click invoice creation from confirmed sales orders or project milestones.
  • Electronic Invoicing: XML & PDF EDI export via account_edi.
  • Check Printing & Deposit: Full support for preprinted checks and bank deposit slips.
  • Payment Gateways: Native integration with Stripe, bank wire, and SEPA QR codes.
🛒

2. Point of Sale (POS), Restaurant & Self-Order

🏪 Retail Register point_of_sale

  • Touchscreen Terminal: Works offline in browser; syncs automatically upon reconnection.
  • Cash Control: Open session → set opening cash balance → record cash in/out.
  • Barcode Scanner: Instant product lookup via USB / Bluetooth scanner.
  • Session Closing: Automatic end-of-day journal entries and bank reconciliations.

🍽️ Restaurant & Bar pos_restaurant

  • Interactive Floor Plan: Configure customizable dining rooms, tables, and seat counts.
  • Order Sending: Dispatch orders directly to kitchen printers or kitchen display screens.
  • Bill Splitting: Split checks by seat, by item, or divide evenly among guests.
  • Table Transfers: Move active orders between tables or combine parties seamlessly.

📱 QR Self-Order & Loyalty pos_self_order

  • Tabletop QR Ordering: Diners scan QR code on their smartphone to order and pay online.
  • Self-Service Kiosk: Full-screen kiosk mode for customer ordering stations.
  • Loyalty Programs: Earn reward points per dollar spent; redeem points for gifts or discounts.
  • Promo Cards: Create digital coupon codes and gift cards (pos_loyalty).

3. OCA Enterprise Replacements: Accounting & Subscriptions

📈 Financial Reports (OCA) account_financial_report

  • Replaces Enterprise Accounting: Free drill-down reports without paying $24/user/mo!
  • Reports Included: General Ledger, Trial Balance, Aged Partner Balances, Partner Ledger.
  • Interactive Drill-down: Click any account balance to expand journal items directly.
  • Native Excel Export: 1-click export to multi-sheet spreadsheets via report_xlsx.

🔄 Subscriptions & Contracts contract

  • Replaces Enterprise Subscriptions: Full automated recurring billing management.
  • Billing Recurrence: Set billing frequency (weekly, monthly, quarterly, annual, custom).
  • Automated Renewal: Cron automatically generates draft recurring customer invoices.
  • Termination Workflows: Track renewals, contract notices, and cancellations.

💼 Community Payroll (OCA) payroll

  • Salary Structures: Configure basic salaries, allowances, overtime, and deductions.
  • Employee Contracts: Define wage rates, working schedule, and tax status.
  • Batch Payslips: Generate hundreds of employee payslips simultaneously each pay period.
  • Accounting Integration: Posts journal entries straight to wage and tax expense accounts.

Part 3 • Administration & FAQ

System Administration & Troubleshooting

Essential management tasks, automated backups, and answers to common operational questions.

💾 How do I perform an automated database backup?

You can dump the complete PostgreSQL database without downtime using the containerized client: 

docker exec -t odoo_db pg_dump -U odoo -F c -b -v -f /var/lib/postgresql/data/backup_$(date +%Y%m%d).dump odoo

🧩 How do I add my own custom or third-party module?

Simply place your module folder inside custom/ or thirdparty/ on your host. Then update the module list in Odoo: 

# 1. In Odoo Web: Enable Developer Mode (Settings -> Activate Developer Mode)
# 2. Go to Apps -> Update Apps List -> Search & Install your module

🔌 What if Port 8069 is already bound by another app?

Change the host port mapping in docker-compose.yml without modifying the container port: 

ports:
  - "8080:8069"  # Maps host port 8080 to container 8069

🔍 How do I enable Audit Logging for sensitive tables?

With OCA auditlog installed, navigate to Settings → Technical → Audit → Rules. Add any model (e.g., res.partner, account.move) and select Create/Write/Delete tracking.
