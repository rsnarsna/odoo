Decoupled, containerized infrastructure isolated through Docker virtual networking with zero credential leaks.

⚙️

Official Odoo 19 Community container preloaded with multi-path addons resolution for core, OCA suites, third-party store modules, and custom apps.

Quick Start with Docker

Spin up the entire stack with a single command.

1. Clone the repository
git clone https://github.com/rsnarsna/odoo.git
cd odoo
2. Set your environment variables
# Windows PowerShell:
Copy-Item .env.example .env

# Linux / macOS:
cp .env.example .env
3. Start the containers
docker compose up -d
4. Access Odoo Web
URL: http://localhost:8069 Credentials: admin / admin
